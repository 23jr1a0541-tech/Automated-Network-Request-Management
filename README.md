Automated Network Request Management
Overview

Automated Network Request Management is a ServiceNow-based workflow automation project that simplifies the process of submitting, approving, and tracking network service requests. The solution uses Service Catalog, Flow Designer, Catalog UI Policies, and custom tables to automate the complete request lifecycle.

Users can submit network requests through a Service Catalog item, after which the system automatically creates records, sends email notifications, manages approvals, updates request statuses, and creates tasks without manual intervention.

Features
Service Catalog-based Network Request form
Dynamic Catalog Variables
Catalog UI Policies for conditional field visibility
Automatic record creation in the Network Database table
Approval workflow using Flow Designer
Automatic status updates after approval
Network task creation for implementation
Email notifications throughout the workflow
Conditional flow logic for approved and rejected requests
Task status tracking and automatic completion updates
End-to-end workflow automation

Workflow
User submits a Network Request.
Catalog variables are captured.
A Network Database record is created.
Email confirmation is sent.
Request is routed for approval.
Upon approval, the request record is updated.
A Network Task is created.
Task notification is sent.
Task completion updates the request status.
Final notification is sent and the workflow ends.
